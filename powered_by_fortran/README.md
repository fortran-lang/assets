# "Powered by Fortran" Logo

The "Powered by Fortran" logo was created by Sebastian Mutz and iterated in a [community-driven discussion](https://fortran-lang.discourse.group/t/powered-by-fortran/11172/62) that was initiated by Austen Rainer of the [FortranFuture Network+](https://www.fortranfuture.net/). It uses the same shade of violet as the ["F" logo](https://github.com/fortran-lang/assets), DejaVu Sans Bold for "powered by", and the Libre Clarendon Wide (Medium Expanded) font for "Fortran". 

There are two versions of the logo (`wide` and `stacked`) for more flexibility. 

It may be used to subtly and visually promote Fortran. You may, for example, use it in your code repository `README` file, user manuals, or conference presentations.
