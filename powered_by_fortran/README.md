# "Powered by Fortran" Logo

The "Powered by Fortran" logo was created by Sebastian Mutz and iterated in a [community-driven discussion](https://fortran-lang.discourse.group/t/powered-by-fortran/11172/62) that was initialised by Austen Rainer of the [Fortran Future Network+](https://www.fortranfuture.net/). It uses same shade of violet as the ["F" logo](https://github.com/fortran-lang/assets), DejaVu Sans Bold for "powered by", and the Libre Clarendon Wide (Medium Expanded) font for "Fortran". 

It may be used to subtly and visually promote Fortran. You may, for example, use it in your code repository `README` file, user manuals, or conference presentations. 

## Versions

Several versions and variants were created for more flexibility. For each version, there is an upper case ("Powered by") and lower case ("powered by") variant. The `badge` and `stacked` versions also have a frameless variant.
